# iOS Agent Team

Use the specialist matching the task: `swiftui-expert` for views and
accessibility, `swift-concurrency-expert` for Swift concurrency,
`swift-testing-expert` for tests, and `ios-reviewer` for review. Use
`ios-lead` when work spans multiple specialties.

Keep deterministic rules, builds, and tests in code. Make the smallest safe
change and verify it with the project’s existing checks.
